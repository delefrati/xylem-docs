# xylem-docs

Public-facing material for [Xylem](https://github.com/delefrati/xylem), a server-first version control system for CI jobs, agents and sandboxes.

- [`index.html`](index.html): **Git wasn't built for agents**, a one-page case for server-first version control. Open it in a browser, or enable GitHub Pages (Settings → Pages → deploy from `main`, root) to serve it.
